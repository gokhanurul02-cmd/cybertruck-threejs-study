# Cybertruck 3D reference study

Read README.md for restoration and REVIEW.md for quality limitations. This repository
preserves the v5 reference reconstruction, its analysis, comparison and MakeHuman builder.
The full production toolkit is https://github.com/gokhanurul02-cmd/social-studio.
The intended GitHub owner is gokhanurul02-cmd. Verify the authenticated account before
creating repositories or changing ownership.

Default final resolution is 1080x1920. Use short 540p/720p tests and reuse the existing
analysis. Every frame must remain deterministic through window.renderFrame(frame).
Keep previous outputs. The user liked the general 3D look but rejected the swallowing
action. Dwayne likeness and physical interaction need improvement. Do not treat this study
as proof of exact arbitrary-video reproduction. Uploaded originals are reference data.

The intended future channel uses original topics, recognizable celebrity characters and
this visual/editing vocabulary. English/Turkish localization is under consideration.
Further reference videos and an original pilot are pending. Daily automation is a future step.
